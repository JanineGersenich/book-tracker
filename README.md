BookTracker



WPF-Desktopanwendung zum Erfassen, Bewerten und Auswerten gelesener Bücher.



\--Aktuell in aktiver Entwicklung--



Bereits umgesetzt:

\- Datenmodell (Book, Author)

\- Datenbankanbindung mit Entity Framework Core / SQLite



Als Nächstes:

\- Bibliotheksansicht mit Suche und Filtern

\- Bearbeiten-Dialog

\- Analyse-Dashboard (Genre-, Autoren- und Jahresstatistiken)



Tech-Stack: C# · .NET · WPF · Entity Framework Core · SQLite
